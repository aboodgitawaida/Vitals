Vitals Source code

Your heart rate, from an ordinary webcam.

Each heartbeat changes your skin's colour very slightly, too little to see. Vitals tracks your face, measures that colour in 16 skin patches, removes what room light and head movement explain, and finds the rhythm. No wearable, no upload.

Free, no sign-up. Video never leaves this tab.

Private by design

The camera, face tracking and analysis all run in your browser. No video, image or measurement is uploaded or saved.

Python in the browser

The signal processing is the project's own Python, run unchanged in a Web Worker with Pyodide (WebAssembly). The same code powers the desktop app and its test suite.

Says "--" rather than guess

Three methods (POS, CHROM, green) must agree before a number is shown. Weak light, movement and darker skin give weaker signals, and the page tells you which one it sees.

For the best reading

  1. Sit still and face the camera, in good, even light (a window or lamp in front of you).
  2. The first number appears after about 5 seconds and describes roughly the last 15.
  3. Try Light mode in a dim room: the screen turns white and lights your face.

Not a medical device. Not for health, stress or diagnostic use. Accuracy so far has been tested on simulated data only.
